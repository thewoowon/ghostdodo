# 01. Product Vision

## 1. Problem

Korean applicants often spend significant time on applications, tests, assignments, and interviews but receive no explicit final disposition. Existing job/community platforms may contain anecdotes, but communication reliability is not usually a first-class, structured metric.

GhostDodo turns that invisible behavior into structured public information.

## 2. Positioning

**Do not position as:**
- blacklist
- revenge board
- anonymous company attack site
- “bad company exposé”

**Position as:**
- recruitment communication transparency database
- applicant-side hiring-process observability
- response reliability benchmark
- community-maintained hiring communication history

Core differentiation:

```text
잡플래닛: 일해본 사람의 회사 데이터
블라인드: 재직자의 내부 이야기
GhostDodo: 지원해본 사람의 채용 커뮤니케이션 데이터
```

## 3. Brand thesis

### Primary hero

**지원하기 전에, 답은 해주는 회사인지 확인하세요.**

### Secondary statement

**답장이 멸종된 회사들을 기록합니다.**

### Product tone

- sharp, witty, dry humor
- not childish
- not vindictive
- data-first
- recognizable Korean internet culture without copying existing IP

## 4. Product nouns

| Term | Meaning |
|---|---|
| GhostDodo | brand/platform |
| Ghost Rate | qualified ghost events / qualified experiences |
| Response Rate | explicit result responses / qualified experiences |
| Ghostory | company-specific chronological communication history |
| 도감 | browsable collection of companies and observed recruitment patterns |
| Dodo Credit | spendable/non-cash contribution credit |
| Reputation | long-term contributor trust score |
| Verified | evidence or corroboration meets verification policy |
| First Discoverer | first qualified contributor for a new company/process pattern; award carefully |

**Never reward “more negative reports.”** Reward completeness, evidence, corroboration, corrections, and helpful context.

## 5. MVP users

### Applicant
Wants to know before investing time:
- Does this company notify rejected applicants?
- At which stage does silence happen?
- What is the median response time?
- Are there recent verified reports?
- Does the company make explicit promises and miss them?

### Contributor
Wants to:
- record an experience
- help future applicants
- gain visible reputation
- receive contribution recognition

### Company representative
Wants to:
- claim company page
- correct factual errors
- add official communication policy
- respond to aggregate issues
- improve transparency score over time

### Moderator
Wants to:
- validate evidence
- remove PII
- handle disputes
- detect coordinated abuse

## 6. Hiring event severity taxonomy

Do not collapse all silence into a single bucket.

### L0 — Not enough evidence
No meaningful company-side interaction or observation window too short.

### L1 — Application Silence
Application submitted, reasonable observation window elapsed, no disposition.

### L2 — Assessment Silence
Test / coding test / assignment completed, no disposition.

### L3 — Interview Ghosting
Interview occurred, then no disposition after reasonable window.

### L4 — Broken Promise
Company explicitly stated a result date/window and failed to communicate after that promise window.

L3/L4 should carry greater analytic weight, but public copy must still remain factual.

## 7. Positive-side taxonomy

Important for neutrality:

- Fast Responder
- Clear Timeline
- Closure Given
- Delayed but Communicated
- Promise Kept

Companies can earn positive badges only from sufficiently large and recent samples.

## 8. Long-term product expansion

### Phase A — Transparency
Search, company pages, reports, metrics.

### Phase B — Community
Comments, follow, contributor profiles, saved companies, useful-report votes.

### Phase C — Application discovery
Company jobs and source links, “지원하러 가기”, saved jobs.

### Phase D — Application tracker
Users track their own stages and expected response dates.

### Phase E — Closed-loop data
With user consent, tracked applications become structured response observations.

### Phase F — Employer tools
Company claim, response SLA, recruiting communication dashboard, transparency badge/API.

## 9. Monetization later — not MVP

Potential options:
- employer transparency dashboard
- verified employer profile
- recruiting communication analytics
- sponsored job placement clearly labeled
- hiring API / benchmark reports

Never allow payment to suppress legitimate reports or alter Ghost Rate.
